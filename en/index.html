BACHELOR'S THESIS · COLLOQUIUM 3 JUL 2026

Human-in-the-Loop Agents in Nursing Robotics: Evaluation and Interactive Application of OCR and VLMs for Processing Handwritten Care Records

An agentic multi-pipeline architecture that processes nursing documentation via a Pepper robot — with a 4-bit quantized Vision Routing Agent for frame selection and an interactive human-in-the-loop system for error correction.

My role
Design, implementation and evaluation of the entire pipeline and the Pepper integration.
Stack
Python · Qwen3-VL · Pixtral (API) · OCR · 4-bit quantization · few-shot prompting · frame sampling/batching · JSON output · Android (Java, QiSDK)
Result
Comparative evaluation of three extraction pipelines (OCR+LLM baseline, VLM few-shot, hybrid VLM-OCR+LLM) on a synthetic N=48 dataset, assessed on transcription quality (ROUGE, BERTScore, medical terminology accuracy) and downstream extraction quality. In-memory processing without data persistence (GDPR-compliant). Human-in-the-loop correction with text-to-speech output as a proof of concept on Pepper hardware.
